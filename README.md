# Bundesliga Spieltag-Vorhersage

Sammelt Bundesliga-Daten (Spiele, Spieler, Marktwerte, Aufstellungen) in Supabase und berechnet vor jedem Spieltag eine Poisson-basierte Vorhersage. Nach dem Spieltag wird automatisch abgeglichen, wie gut die Vorhersage war.

Vollstaendige Doku, Setup-Schritte und Modell-Erklaerung: siehe Original-Zip / spaeter zu ergaenzen.

Ordnerstruktur: scripts/ (Fetcher + Modell), sql/ (Schema-Backup), .github/workflows/ (Cron-Pipeline).
